# Readable paper explanations

Use ordinary Markdown and code spans for identifiers, values and short assignments: `A = 3`, `ioctl`, `[0, 8)`. Use math delimiters for mathematical notation: $x_i$ or a display equation on separate lines. Never wrap dollar-delimited math inside backticks: write `A = 3` or $A=3$, never `$A=3$`. Keep real source code in fenced code blocks. Define notation before using it, and prefer prose or a small table when they make an intermediate representation easier to understand.
